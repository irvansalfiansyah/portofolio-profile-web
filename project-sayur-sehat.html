Sayur Sehat E-Commerce

Role: Software Quality Assurance Year: 2026

About Project

Sayur Sehat E-Commerce is an innovative digital e-commerce platform focusing on the distribution of organic vegetables and fresh produce directly to consumers. The project is built using a high-speed modern architecture with a React (Vite) frontend and a reliable, high-performance backend using Go (Golang) and PostgreSQL.

In this project, I acted as the Software Quality Assurance (SQA) Engineer, designing and implementing a comprehensive testing strategy to ensure the system's quality and reliability prior to deployment.

Testing Scope & SQA Documentation

  • Combined Testing Methodology: Utilized Black Box testing to validate visual functionality, White Box testing to analyze Go backend logical code paths, and Grey Box testing to verify API integration against the PostgreSQL database schema.
  • Comprehensive SRS Documentation: Compiled Software Requirements Specification (SRS) documentation detailing all use cases, functional descriptions, data relationship diagrams, and system constraints.
  • Test Case Specifications: Prepared detailed test scenarios covering JWT authentication modules, shopping carts, checkout payment flows, and concurrent stock level validations.
  • Bug Tracking & Defect Reporting: Used a structured defect tracker to document, prioritize (severity level), track reproduction steps, and validate fix patches submitted by the development team.
