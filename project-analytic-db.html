Product Sales Analyzer (PPP)

Role: Full-Stack Developer Year: 2026

About Project

Product Sales Analyzer (PPP) is an integrated full-stack sales analytics dashboard application designed to monitor sales performance, product analytics, transaction management, and secure bulk CSV data imports.

The project is built using Clean Architecture on the backend to ensure scalability and long-term maintainability. For the frontend, the application adopts a premium minimalist monochromatic UI inspired by shadcn/ui ("Clinical Blueprint") with a custom Ember accent color.

Key Features

  • Overview Dashboard: Key Performance Indicator (KPI) cards displaying total daily/monthly revenue, total order quantity, average order value, growth rate, as well as Recharts-based daily sales trends and product category proportions.
  • Product Analytics: Interactively displays the top 10 best-selling products by units sold, along with aggregated volume and revenue insights cards.
  • Sales Reports & Export: Detailed sales transaction tables with column sorting, dynamic date range and transaction status filters, and instant exports to Excel (.xlsx) or PDF (.pdf) documents.
  • Bulk CSV Import: Drag-and-drop interface to upload master product and sales order CSV files, featuring a backend parser and real-time, line-by-line error validation.

Technologies & Tools

React.js Vite Node.js Express.js PostgreSQL Tailwind CSS Recharts JWT & Bcrypt ExcelJS & PDFKit
