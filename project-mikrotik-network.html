MikroTik Cafe Network Implementation

Role: Network Engineer Year: 2026

About Project

This project involved designing and implementing a structured, secure, and manageable network infrastructure for Cafe Kopi Bandung, a local coffee shop accommodating up to 40 active customers.

Prior to this implementation, the cafe suffered from frequent network instability, IP address conflicts, and security vulnerabilities due to a flat consumer-grade router setup with no bandwidth management or client isolation. The new system utilizes a MikroTik RouterBOARD to control traffic routing, security filtering, and client access management.

Key Features

  • Network Segmentation (VLAN/Subnets): Divided the physical network into isolated subnets to keep critical business systems (PC POS, CCTV storage) separated from client internet access.
  • MikroTik Hotspot Captive Portal: Implemented a customized captive login portal for guests, ensuring that customers must authenticate before accessing the internet.
  • DHCP & Static Leases: Automated dynamic IP configurations for guests alongside static lease bindings to ensure essential internal hardware (cash registers, security cameras) maintain persistent IPs.
  • Firewall NAT & Security Filtering: Configured NAT Masquerade for shared internet access, alongside inbound packet filtering to shield internal components from internet-borne threats.
  • Local DNS Caching & Mapping: Enabled DNS request caching on the router to accelerate browsing speeds and created static local DNS hostnames (e.g., router.cafe).
